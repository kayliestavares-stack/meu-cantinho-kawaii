# Meu Cantinho Kawaii ♡

Protótipo inicial de um site pessoal rosa kawaii.

## Como visualizar
Abra `index.html` no navegador. Para editar, abra `admin.html`.

## O que já tem
- Página pública com perfil, descrição e links
- Galeria de fotos
- Fundo personalizável
- Música com controle de reprodução/volume do navegador
- Painel para editar título, descrição, links, fotos, cor e música

## Importante antes de publicar
Este é um protótipo local. As alterações são guardadas no `localStorage` do navegador e arquivos grandes podem exceder o limite do navegador. Isso **não** sincroniza as alterações com outras pessoas nem protege o painel. Não coloque senhas ou informações privadas aqui.

Para virar um site público de verdade com painel privado, precisamos conectar um backend (por exemplo, Supabase) para autenticação, banco de dados e armazenamento, e então publicar a página. O GitHub serve para guardar o código; GitHub Pages pode hospedar a parte pública, mas não oferece login/admin seguro por si só.

A música não começa automaticamente: visitantes precisam apertar play, pois navegadores normalmente bloqueiam áudio automático.
